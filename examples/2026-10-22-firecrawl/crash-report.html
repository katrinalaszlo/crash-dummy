PASS Scenario 1: happy path

example.com in 274 ms, firecrawl.dev in 1.8 s (30 k chars of markdown), a docs page in 1.4 s. map → 20 links, blocking crawl → completed, search → 3 web results with no provider configured. Same scrape through the Next.js route.

PASS Scenario 2: limits

Bad URL → 400 with three specific validation messages. 404 target → metadata.statusCode 404 + metadata.error. localhost target rejected with a clear message. Wrong apiUrl → FirecrawlSdkError wrapping ECONNREFUSED.

FAIL Scenario 2b: unsupported formats

screenshot: success: true, no screenshot field, no warning to the caller (server log only). json with no LLM key: generic 500 "check your logs"; real cause is an empty OPENAI_BASE_URL string producing a request to /responses.

NOT TESTED Scenario 3 / 4

No admin or config surface in the default stack; the queue UI needs BULL_AUTH_KEY, which the docs say to leave unset.
